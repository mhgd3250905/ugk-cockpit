# 工作台界面重构记录 · 2026-09-05

## 目标与实施范围

用户要求保留时间线管理理念，重构简陋、重复的界面，提升日常使用的美感和操作愉悦。当前实现采用常驻项目导航、按状态分组的项目行、默认工作线页签和当前工作侧栏。工作说明、开发空间分别进入独立页签，仍保留原有操作与状态。

视觉基线见 [DESIGN.md](../DESIGN.md)，产品原则见 [PRODUCT.md](../PRODUCT.md)。石墨暗色、雾灰亮色共用语义令牌；项目切换、页签、展开与聚焦提供短促反馈，并尊重系统减弱动态效果设置。项目摘要取真实最近记录的首行，完整内容保留在时间线。

本轮前端不修改数据库、项目代码位置、工作副本或工作会话，不改变工作线归属、来源、合流或分页规则。服务数据恢复的既有问题另见 [本地服务恢复记录](LOCAL_SERVICE_RECOVERY.md)。
