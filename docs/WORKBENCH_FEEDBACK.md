### 摸排结论

- 用户确认问题发生于 Chrome / Edge 等系统浏览器。现有待办接口返回完整 `copyText`（本次样本 3185 字符），普通 Chromium 环境原实现可以写入并粘贴完整文本；用户原浏览器的具体失败条件尚未直接复现。
- 原实现只调用 `navigator.clipboard.writeText`，没有失败后的可用复制入口；失败会向按钮上方插入警告。成功后按钮由「复制说明」变为更长的「已复制处理说明」，2.5 秒后再变回，可引发布局重排。复制错误与待办状态错误共用状态，后续复制成功还会留下旧错误。
- 新实现始终复制接口提供的完整说明与处理指令，不截断、不替换成可见正文。优先使用异步剪贴板接口；兼容选区复制仅在前者失败或不可用时尝试，并检查返回结果；均未成功时明确引导手动复制，不显示成功。
- 手动入口始终可见，供浏览器已响应成功但用户仍无法粘贴时使用。弹窗自动全选、支持键盘复制与再次全选；只读内容不写回待办。复制期间屏蔽重复点击，复制反馈保持独立，移除延时更改按钮文案。
