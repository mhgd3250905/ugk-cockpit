# 工作线时间线

## 目标

项目运行详情把主项目与各工作副本画成稳定的多条工作线。时间线仍按最新记录在上方展示；事件交错时，用户通过轨道、工作副本名称和卡片摘要判断归属，不需要理解内部 ID。

## 数据语义

- 轨道身份来自稳定的 `worktreeId` 与项目的开发空间记录。颜色绑定轨道身份，不能绑定 Agent、事件类型或 `branch` 名称；同名工作线属于不同工作副本时仍分开。
- 主项目固定使用主轨；`RELAY` 是当前工作会话中的非终态记录，一直留在产生它的原轨道。
- 系统创建开发空间是可确认的来源锚点，可显示轻量“工作副本来源”行并从主轨画出来源曲线。缺少来源关系的记录进入“来源未确认”独立轨，不根据相邻事件或分支变化补 ancestry。
- 只有 `integration_receipts.outcome = 'integrated'` 且存在 `integrated_commit`，并且回执明确指向主项目的，才生成“接入主项目”节点和来源轨到主轨的接入关系。送审、领取、审核通过、普通 `HANDOFF` 或同一 SHA 不代表合流。
- 分页只返回已加载事件；来源早于当前页时在列表底部显示“来源较早记录”延续行，提示继续加载更早记录，不把未加载事件算作已展示。来源元数据不计入事件总数。

## 交互与可读性

- 默认所有轨道、节点和卡片正常显示。
- 点击任意轨道节点，或卡片的非按钮、链接、`summary` 区域，选择对应整条工作线；用 `aria-pressed` 和可访问名称暴露选择状态。再次点击已选线保持选择；「显示全部」清除选择。
- 非选中轨道继续占据原位置，不删除、不重排、不重新连线。通过表面层次、边框和轨道透明度弱化，但正文保持可读；详情展开、复制、链接和对话框关闭等已有控件不会触发聚焦。
- 卡片统一左边界，轨道宽度随轨道数量和内容宽度受限计算。窄屏保留两到三条可辨轨道，更多轨道通过稳定间距和滚动的轨道筛选控件处理；不会把卡片无限向右缩进。
- 分叉与已确认接入使用紧凑 Metro smooth-step：约 2px 线宽、圆角端帽与衔接、两端短竖向切线和统一受限半径；半径按实测轨距与纵向落差计算，来源锚点默认在目标节点下方约 28px，并受工作线来源末端截断。节点与引线使用实际 `article` 的 border-box 中点，细引线从节点下方连续贴到卡片左边界，详情展开、分页和窄屏重测后仍保持同一中心。
- 主题使用现有深浅色令牌，轨道色与绿色状态色分离；`prefers-reduced-motion: reduce` 关闭时间线进场和过渡动效。

## 验收

应覆盖不同工作副本交错、同名工作线、主线 `RELAY`、来源未知、无集成回执不合流、真实集成回执、分页身份稳定、刷新/展开后保持选择、暗淡卡片仍可切换、窄屏多轨、键盘操作和原有详情交互。
