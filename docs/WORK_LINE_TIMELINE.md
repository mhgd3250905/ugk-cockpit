# 工作线时间线

## 目标

项目运行详情把主项目与各工作副本画成稳定的多条工作线。时间线仍按最新记录在上方展示；事件交错时，用户通过轨道、工作副本名称和卡片摘要判断归属，不需要理解内部 ID。

## 数据语义

- 轨道身份来自稳定的 `worktreeId` 与项目的开发空间记录。颜色绑定轨道身份，不能绑定 Agent、事件类型或 `branch` 名称；同名工作线属于不同工作副本时仍分开。
- 主项目固定使用主轨；`RELAY` 是当前工作会话中的非终态记录，一直留在产生它的原轨道。
- 系统创建开发空间是可确认的来源锚点，可显示轻量“工作副本来源”行并从主轨画出来源曲线。缺少来源关系的记录进入“来源未确认”独立轨，不根据相邻事件或分支变化补 ancestry。
- 只有 `integration_receipts.outcome = 'integrated'` 且存在 `integrated_commit`，并且回执明确指向主项目的，才生成“接入主项目”节点和来源轨到主轨的接入关系。送审、领取、审核通过、普通 `HANDOFF` 或同一 SHA 不代表合流。
- 新版 `submit_note` 只显示来源工作副本发布过一条工作说明，不代表审核通过、分支完成或合流。待办状态与发布事件分离，标记处理或归档不改写发布时的正文和来源。
- 分页只返回已加载事件；来源早于当前页时在列表底部显示“来源较早记录”延续行，提示继续加载更早记录，不把未加载事件算作已展示。来源元数据不计入事件总数。

## 交互与可读性

2026-09-12（alpha.43 源码）：轨道在结束节点收尾，重新打开后续画，关闭期间不连接；所选已结束工作线展示“最后工作”。关闭标记只撤销尚未接入的邀请，已经接入的 AI 会话仍需正常交接。完整信息弹窗中的会话接续与转交按工作副本过滤，历史已结束会话折叠；关闭弹窗和切换工作线不丢失当前项目页面内的转交原请求与晚到回执。

项目“从工作台移除”与归档分开：软移除保留本地代码及历史，显式重新添加恢复展示；开发空间的删除仍是独立受保护操作。

2026-09-08 补充：用户可手动关闭或重新打开非主项目工作线，状态与历史事件通过独立 revision 和幂等命令保存。手动记录显示为用户操作，不伪造 Agent、Git 证据、正式 handoff 或接入主项目回执；原有代码与历史保留。复用工作副本时，在结果事务中重新打开原先关闭的工作线。

项目详情按所选工作线展示工作目标、会话与最近记录的代码状态，完整信息按需打开；无记录时明确提示，不把其他工作线的会话或代码证据填入当前线。代码信息保留观察时间，不代表实时文件状态。项目归档是独立的用户记录，不改写原阶段和代码记录，也不等于删除工作副本。

- 默认所有轨道、节点和卡片正常显示。
- 点击轨道节点或工作线名称按钮，选择对应整条工作线；用 `aria-pressed` 和可访问名称暴露选择状态。再次点击已选线保持选择；「显示全部」清除选择。
- 最新事件适度展开，历史默认两行摘要，按日期分段。点击摘要按钮或事件卡片空白展开/收起；按钮以 `aria-expanded` 与 `aria-controls` 暴露状态。选择工作线时默认展开该线的最新事件；手动展开状态在轮询及分页时保持，切换聚焦范围时恢复默认。完整原文、接力/交接上下文、Git 证据与统计信息仍在记录详情中。
- 曲线高亮按曲线所属工作线判断：分叉弯线随分出的工作线聚焦，接入弯线随接入来源工作线聚焦；选择主项目不会替开发工作线曲线提亮。节点到卡片的细引线始终保留，未选中时以可辨认的淡色显示，并与节点和卡片边界连续衔接。
- 非选中轨道继续占据原位置，不删除、不重排、不重新连线。通过表面层次、边框和轨道透明度弱化，但摘要保持可读；详情展开、复制、链接和页面返回等已有控件不会触发聚焦。
- 卡片统一左边界，轨道宽度随轨道数量和内容宽度受限计算。窄屏保留两到三条可辨轨道，更多轨道通过稳定间距和滚动的轨道筛选控件处理；不会把卡片无限向右缩进。
- 分叉与已确认接入使用紧凑 Metro smooth-step：约 2px 线宽、圆角端帽与衔接、两端短竖向切线和统一受限半径；半径按实测轨距与纵向落差计算，来源锚点默认在目标节点下方约 28px，并受工作线来源末端截断。节点与引线使用实际 `article` 的 border-box 中点，细引线从节点下方连续贴到卡片左边界，详情展开、分页和窄屏重测后仍保持同一中心。
- 主题使用现有深浅色令牌，轨道色与绿色状态色分离；`prefers-reduced-motion: reduce` 关闭时间线进场和过渡动效。

## 验收

应覆盖不同工作副本交错、同名工作线、主线 `RELAY`、来源未知、无集成回执不合流、真实集成回执、分页身份稳定、刷新/展开后保持选择、暗淡卡片仍可切换、窄屏多轨、键盘操作和原有详情交互。
